## Project Overview

A full-stack web portfolio developed as a final project for the Web Technologies course at Haliç University. Built with HTML5, CSS3, JavaScript, PHP, and MySQL.

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic structure |
| CSS3 | Responsive design, Flexbox, Grid, CSS Variables |
| JavaScript | DOM manipulation, form validation, AJAX |
| PHP 8 | Server-side logic, session management |
| MySQL | Database for projects and contacts |

---

## Features

- Responsive design with dark/light mode toggle
- Projects loaded dynamically from MySQL via AJAX
- Contact form with JS + PHP double validation, saved to database
- Admin dashboard with session-based authentication
- Add/delete projects and contact messages from admin panel

---

## Database Schema

- **projects** — id, title, description, tags, link, created_at  
- **contacts** — id, name, email, message, created_at  
- **admin_users** — id, username, password (bcrypt hashed)
